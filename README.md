# D-tection-automatique-des-bouteilles-vides
Conception d’un système automatisé de détection et d’éjection des bouteilles vides sur un convoyeur, utilisant un automate Siemens S7-300, le logiciel TIA Portal et la programmation Ladder. Deux capteurs détectent les bouteilles et identifient les vides, tandis qu’un registre à décalage commande un vérin après cinq étapes.
